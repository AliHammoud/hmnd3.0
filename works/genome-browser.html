Case 01 / 03Pharma R&D · Genomics2023

Genome intuition, made legible.

Software that captures how scientists actually reason about variants — without exporting the insight to a desktop tool.

A research team had genomic insight locked in notebooks and ad-hoc scripts — intuition that never reached the shared system. We co-architected a genome browser and annotation workflow with embedded scientists, preserving how researchers think about variants.

Challenge
Turn tacit genomic reasoning into software scientists would actually use — without forcing them into a workflow that erased how they think about variants.
What we did
  1. 01Mapped how scientists navigate variants across notebooks, scripts, and tribal knowledge.
  2. 02Co-architected the browser and annotation workflow with embedded domain scientists.
  3. 03Preserved researcher agency in the interface instead of flattening intuition into rigid forms.
  4. 04Shipped decision-ready views inside the platform so insight no longer lived only on desktops.
Outcome
Scientists stopped exporting to desktop tools. Decision-ready views shipped inside the platform.
